# Oxyria_thesis
R script for all code used for the master thesis "Different phylogenetic relationships within the genome of European Oxyria digyna". Sofie Kedbäck 2026-03-04 to 2026-05-08. OBS Not all results are included in the final thesis.

# Code includes
Visualise TreeMix phylogenies, Midpoint root TreeMix nexus-file, Find number of TreeMix migration edges needed to explain the data, Find most common topology and pattern (placement and direction) of migration edges, Compare topologies with Robinson-Foulds distances.
